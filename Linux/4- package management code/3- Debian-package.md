# Debian-Based Distributions

## `dpkg` Package Manager

| Short | Long | Description |
|:----:|------|-------------|
| `-c` | `--contents` | Displays package contents |
| `-C` | `--audit` | Searches for broken packages |
| N/A | `--configure` | Configures an installed package |
| N/A | `--get-selections` | Lists installed packages |
| `-i` | `--install` | Installs or upgrades a package |
| `-I` | `--info` | Displays package information |
| `-l` | `--list` | Lists installed packages |
| `-L` | `--listfiles` | Lists installed files |
| `-p` | `--print-avail` | Displays package information |
| `-P` | `--purge` | Removes package and configuration files |
| `-r` | `--remove` | Removes package but keeps configuration files |
| `-s` | `--status` | Shows package status |
| `-S` | `--search` | Finds which package owns a file |

## APT Package Manager

| Action | Description |
|----------|-------------|
| `autoclean` | Removes obsolete package information |
| `check` | Checks package database integrity |
| `clean` | Removes cached package files |
| `dist-upgrade` | Upgrades packages while resolving dependencies |
| `dselect-upgrade` | Completes pending package changes |
| `install` | Installs or updates a package |
| `remove` | Removes a package |
| `source` | Downloads package source code |
| `update` | Updates repository metadata |
| `upgrade` | Upgrades installed packages |
