# 2- openSUSE

> Uses the **`zypper`** package manager.

## Zypper Commands

| Command | Description |
|----------|-------------|
| `help` | Displays general or command-specific help |
| `install` | Installs a package |
| `info` | Displays package information |
| `list-updates` | Lists available updates |
| `lr` | Lists configured repositories |
| `packages` | Lists available packages |
| `what-provides` | Finds which package owns a file |
| `refresh` | Refreshes repository metadata |
| `remove` | Removes a package |
| `search` | Searches for packages |
| `update` | Updates packages |
| `verify` | Verifies installed package dependencies |
